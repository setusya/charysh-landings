## Как открыть локально

React + Babel компилируются в браузере, поэтому нужен локальный HTTP-сервер
(через `file://` JSX не загрузится).

### Python
```bash
python -m http.server 8000
# http://localhost:8000/privatecamps.html
```

### Node
```bash
npx live-server --port=5500
```

### VS Code
Установить расширение **Live Server** → ПКМ по `privatecamps.html` →
*Open with Live Server*.

## Структура

```
components/   React-компоненты всех секций (.jsx)
assets/       Фотографии, рендеры, иконки
fonts/        Шрифты
*.css         tokens.css · site.css · privatecamps.css · familycamp.css
```
